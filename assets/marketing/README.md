# Marketing shots

Screenshots and clips of the game for tweets, one per feature, generated by
`scripts/promo.mjs` (see the header of that file). Names are `<version>-<what>.png` for
stills and `<version>-clip-<what>.gif` for clips, so a tweet about the lens is
`v0.8-lens-fine-print.png` and the play-through clip is `v0.8-clip-solve-a-case.gif`.
`node scripts/promo.mjs clips` also writes each clip as a 1280×720 H.264 MP4 (`*.mp4`, not
committed; needs Google Chrome installed): those are what the Typefully drafts carry.

Stills are 1280x720 (exactly twice the game's 640x360, so pixels stay crisp). Clips are
640x360 GIFs at ~12 fps; Twitter turns them into video on upload. For MP4s run them
through ffmpeg: `ffmpeg -i in.gif -movflags faststart -pix_fmt yuv420p out.mp4`.

Regenerate after a change with the dev server running:

    node scripts/promo.mjs            # everything
    node scripts/promo.mjs shots      # stills only
    node scripts/promo.mjs clips      # clips only
    node scripts/promo.mjs lens       # one entry by name
    PROMO_TAG=v0.9 node scripts/promo.mjs

Tweet copy for each asset is in `TWEETS.md`. The scheduled queue (two weeks, Paris times,
pushed to Typefully) is `queue.json`, rendered to `QUEUE.md` by `node scripts/queue.mjs`; the
promotion playbook is [`docs/PROMO.md`](../../docs/PROMO.md).
