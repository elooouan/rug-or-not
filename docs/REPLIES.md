# Replying on X — the voice, with examples

Rules from [PROMO.md](PROMO.md) §8, made concrete. Two voices: **you** (builder: facts,
numbers, what shipped) and **Lucien** (deadpan, one line, never explains the joke). Pick one
per reply; never both. Short beats clever. A screenshot beats a paragraph.

Never: "great question", "thanks for the support", "stay tuned", rocket emojis, "we" when
it's you, arguing about price, replying twice to the same troll.

## Common comments and what to say

**"wen token / wen launch"**

> Lucien: When you've read the tokenomics.
> You: When the LP lock and the contract are ready to post in one tweet. Not before.

**"is this a rug lol"**

> You: Fixed supply, no mint, LP locked (link in the pinned thread), contract verified. Run the
> game's own red-flag list against it, that's what it's for.

**"link?"** (reply with the link, always, even though it's in the bio)

> You: https://elooouan.github.io/rug-or-not/ — browser, free, phone sideways.

**"what engine / how is it made"**

> You: Phaser 3 + TypeScript. Every texture is drawn in code from twelve palette colours; the
> only PNGs are Lucien. Repo's public: github.com/elooouan/rug-or-not

**"AI art?" / "AI slop"**

> You: Lucien is hand-drawn. Everything else on the desk is procedural pixel art, drawn in
> code. The cases are written by hand; the cold cases are generated from the same 18 flags.

**"can I make my own case?"**

> You: Yes. /editor.html on the same host, same documents and clues, and a share link opens
> your file for anyone.

**"does it work on mobile"**

> You: Sideways, in the browser. The lens floats above your finger. Add it to the home screen
> for a full-screen desk.

**"this red flag is wrong / actually X is fine"** (take it seriously; it's free QA)

> You: Fair point on [X]. The notebook page says [Y]; if [Z] holds I'll reword it. What
> would you change?

**"found a bug"**

> You: On it. → later: Fixed in [short hash], live in a minute. Thanks for the file.

**"how much did you make / how many players"**

> You: The Hall of Detectives is public. Count the rows.

**"price prediction?" / "will it 100x"**

> Lucien: I stamp files, not charts.
> (Nothing else. Ever.)

**Impersonators, "official" links in replies, fake CAs**

> You: Only address is in the pinned thread. Report the reply and move on. (Then report it.)

**"this is just a quiz game"**

> You: Sixteen written cases, an endless printer, a sixty-second rush, herring hunts, a
> second look at every miss, a desk you dress with what the files pay. Play one file
> before deciding. Free.

**Someone posts their detective ID card**

> You: [their rank] in [n] files. The [flag they missed most, if visible] gets everyone. Pinned
> to the wall next Sunday. (Ask "mind if I repost?" before quoting it.)

**A rug hunter posts a post-mortem**

> You (quote-tweet): Lucien's three flags on this one: [flag], [flag], [flag]. All in the
> contract, none in the chat. (Only from public post-mortems; never name victims, never a
> live project.)

## Timing

Reply within the first hour on your own tweets. On big accounts, reply inside five minutes
of their post or don't bother. Two 30-minute sessions a day, 15:30 and 21:00 Paris.

Paste comments into the Claude Code session and it will draft replies in this voice.
